# Yoink head

YoinkV2's Discord avatar (black face, pink angry brows, eyes and a "w" mouth) as a Minecraft player head.

- `yoink-skin.png`: 64x64 classic skin, black head with the 8x8 pixel face on the front (brows joined to the eyes, a
  lighter highlight pixel in each eye), dark body. `yoink-face-preview.png`: the face scaled up.
- The skin was signed through MineSkin (unlisted), so the texture is hosted by Mojang; `texture.json` has the texture
  value and URL, `give-command.txt` the command (`@p` -> any player name). Works on every 26.x server.
