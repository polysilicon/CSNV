# [OG] Merchant (Anarchy)

A shop villager in the market (`crispy:market`, -102.5 95 -68.5, on the street just outside the bank's east door) that only trades with
players **wearing** the [OG] tag. The gate is the chat-tags mod's: the villager is tagged `needtag.og`, so anyone not
wearing [OG] gets "This [OG] Merchant needs [OG] equipped", with a click to equip it if they own or can get it.

Trades (Gold Coins, the market currency): OG Blade (netherite sword, Sharpness V, Looting III) 48, OG Pickaxe
(Efficiency V, Fortune III) 48, OG Wings (elytra) 32, Mending book 16, enchanted golden apple 12, totem 8,
OG Stash (shulker box) 10, 64 rockets 4.

- Install: `datapack/` as `world/datapacks/crispy_og`, `/reload`, then `/function og:place`.
- The market's own `spawn_shops`/reinstall kills every `crispy_shop` villager, so run `/function og:place` again after.
- `/function og:remove` takes it away.
